# Phase 0 评测计划

## 1. 目标

Phase 0 只回答一个核心问题：

> **哪个模型最适合项目里的哪个角色？**

而不是泛泛问“谁最强”。

## 2. 本轮要比的角色

1. **协调员**：是否会问对问题，是否会稳住结构化输出
2. **噪音分析专家**：是否能把用户描述转成可执行结论
3. **购物抽取推理器**：是否能把商品文本变成结构化字段
4. **购物总结器**：是否能给出可落地的比价建议

## 3. 打分原则

### 自动评分先看三件事

1. **JSON 能否解析**
2. **必填字段是否齐全**
3. **关键词是否覆盖**

### 人工复核再看三件事

1. 有没有明显胡说八道
2. 有没有遗漏关键信息
3. 输出是否真的适合后续系统消费

## 4. 通过门槛建议

### 协调员模型

- JSON 解析成功率 ≥ 95%
- 平均分 ≥ 0.80
- 不能频繁漏问预算 / 窗型 / 是否可加内窗

### 噪音分析模型

- JSON 解析成功率 ≥ 95%
- 平均分 ≥ 0.80
- 不应把明显低频交通噪声判断成纯中高频

### 购物抽取推理器

- JSON 解析成功率 ≥ 90%
- 平均分 ≥ 0.78
- 规格、价格、店铺、关键词提取不能经常丢字段

### 购物总结器

- JSON 解析成功率 ≥ 90%
- 平均分 ≥ 0.78
- 要能给出“适合谁买 / 风险点 / 为什么”三类信息
