# 搜索页探针使用说明

> 作用：在第一次真实淘宝联调时，先检查“搜索页候选提取和选择器命中情况”，减少直接跑完整链路的排障成本。

## 命令行用法

```bash
uv run python src/phase1_cli.py probe-search-query \
  --query "隔音窗 夹胶中空 系统窗 性价比"
```

## 当前会输出什么

- 搜索词
- 搜索 URL
- 风险识别结果
- 各候选卡片选择器命中计数
- 提取出来的候选商品预览
- 搜索页正文预览与长度

## 什么时候先用这个命令

适用于以下场景：

1. `search-once` 返回空候选
2. 候选里混入大量噪声商品
3. 怀疑列表页结构改版
4. 想先看选择器命中情况，而不是直接跑完整工作流
