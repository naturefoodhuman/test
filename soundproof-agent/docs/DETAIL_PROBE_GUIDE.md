# 详情页探针使用说明

> 作用：在第一次真实淘宝联调时，不必一上来就跑完整工作流，可以先对单个详情页做“原始探针诊断”。

## 命令行用法

```bash
uv run python src/phase1_cli.py probe-detail-url \
  --detail-url "https://item.taobao.com/item.htm?id=123456"
```

## 当前会输出什么

- 风险识别结果
- 标题候选选择器命中
- 店铺名候选选择器命中
- 价格候选选择器命中
- 正文文本长度
- 正文预览

## 为什么需要这个命令

因为真实页面第一次联调时，最常见的问题不是“工作流整体报错”，而是：

1. 标题没抓到
2. 店铺名没抓到
3. 价格抓错
4. 正文很短或为空

如果直接跑完整 live-demo，排错成本更高；先用 probe-detail-url 可以更快定位是哪个选择器出了问题。
